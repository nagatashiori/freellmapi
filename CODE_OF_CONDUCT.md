# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone and to act with empathy, respect, and professionalism.

## Expected behavior

- Give and gracefully accept constructive feedback.
- Protect private information and credentials.
- Focus feedback on the work and its impact.
- Accept responsibility for mistakes and correct them.

Unacceptable behavior includes harassment, threats, insults, publishing private information, or other conduct that would be inappropriate in a professional setting.

## Enforcement

Report unacceptable behavior through the repository's private GitHub security or administrator channel. Do not publish private operational details in a public issue.
